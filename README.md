# АкТАУН — каталог семи сайтов

Готовая самостоятельная папка для публикации. На главной странице — семь превью и ссылки. В каждом варианте есть кнопка «Все варианты» и переходы к соседним сайтам. Изображения, шрифты, галереи и анимации включены; цены не показываются.

Репозиторий: https://github.com/copycentremama/Actown

Адрес каталога после публикации: https://copycentremama.github.io/Actown/

## Опубликовать через GitHub Pages

1. Используйте репозиторий `copycentremama/Actown`.
2. Загрузите **содержимое этой папки в корень репозитория**: `index.html` должен оказаться прямо в корне, рядом с папками `01-main` … `07-signal` и `_shared`.
3. Сохраните скрытые файлы `.nojekyll` и `.github/workflows/pages.yml`. В Windows Проводнике включите показ скрытых элементов; удобнее загрузить через Git или GitHub Desktop.
4. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. Откройте вкладку **Actions**, выберите **Publish catalogue** и нажмите **Run workflow**, если публикация ещё не началась после загрузки.
6. После успешной публикации адрес будет `https://copycentremama.github.io/Actown/`. Его можно отправить заказчику.

Простой альтернативный способ: в Pages выбрать **Deploy from a branch**, ветку **main**, папку **/(root)** и Save. При таком способе файл workflow можно не загружать. `.nojekyll` необходимо оставить.

Если загружаете архив через браузер GitHub, сначала распакуйте его на компьютере. GitHub не распаковывает ZIP в структуру сайта.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Что работает

- Все семь сайтов на компьютере и телефоне.
- Фильтры, просмотр фотографий, клавиатурная навигация и выбор услуг.
- Переключатели примеров, подсветки, этапов и анимаций.
- Относительные ссылки: каталог работает и под именем репозитория, и на отдельном домене.

Это каталог для просмотра дизайна. Формы проверяют заполнение, но **не отправляют заявки и не сохраняют данные**. Телефоны и адрес почты остаются обычными ссылками. Сервер и база данных не входят в эту папку.

## Локальный просмотр

Из этой папки запустите `python -m http.server 8080` и откройте `http://localhost:8080/`. Либо используйте Live Server. JavaScript-модулям нужен HTTP; открытие `index.html` двойным щелчком через `file://` не подходит для проверки интерактива.

## Структура

`index.html` — каталог; `01-main` … `07-signal` — сайты; `_shared` — изображения, шрифты, стили и сценарии; `catalogue.css`, `catalogue.js` — оформление каталога; `review.css` — навигация между вариантами.
